# Dvin — дизайн сайта гостевого дома

Одностраничный лендинг с атмосферой «река + сосны + утро».

## Концепция

- **Палитра:** глубокий сине-зелёный (река), хвойный зелёный, песочный крем
- **Шрифты:** Cormorant Garamond (заголовки) + Manrope (текст)
- **Секции:** Hero, о доме, номера, удобства, галерея, отзывы, как добраться, бронирование

## Подключить ваши фото с рабочего стола

1. Положите изображения в `Desktop\картинки`
2. В PowerShell в папке сайта выполните:

```powershell
cd C:\Users\QWERTY_\dvin-guesthouse
.\setup-images.ps1
```

3. Откройте сайт через локальный сервер (важно для загрузки manifest):

```powershell
npx serve .
```

## Запуск

Откройте http://localhost:3000 после `npx serve .` (не двойной клик по index.html, если фото не грузятся).

## Что подставить свои данные

- Адрес и координаты в блоке «Как добраться»
- Телефон, Telegram, email
- Фото: замените URL Unsplash на свои в `css/style.css` и HTML
- Карта: вставьте iframe Яндекс.Карт в `.map-placeholder`
- Форма: подключите Telegram-бот, почту или CRM

## Деплой

Можно залить как статику на любой хостинг или встроить в Node-проект на Bothost.
