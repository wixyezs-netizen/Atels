# Сайт ателье + админ-панель

Публичный сайт с услугами, электронной очередью (номерки) и админ-панелью для управления контентом, фото, контактами и SEO.

## Возможности

- **Сайт:** услуги с фото и ценами, текущий номер очереди, онлайн-запись, контакты и мессенджеры
- **Админ** (`/admin`): очередь, услуги, настройки, SEO, смена пароля
- **SEO:** `robots.txt`, `sitemap.xml`, meta-теги, Open Graph, Schema.org LocalBusiness, верификация Google

## Локальный запуск

```bash
cd atelier-site
npm install
npm start
```

Сайт: http://localhost:3000 (или http://127.0.0.1:3000 — **не** http://0.0.0.0:3000)  
Админ: http://localhost:3000/admin  
Пароль по умолчанию: `admin123` (смените в разделе «Безопасность»)

## Деплой на Bothost

Bothost запускает Node.js-приложения из Git. Подойдёт этот проект как **веб-приложение** (не Telegram-бот).

1. Создайте репозиторий на GitHub/GitLab и загрузите проект.
2. На [bothost.ru](https://bothost.ru) создайте проект с платформой **Node.js**.
3. Укажите:
   - **Главный файл:** `server.js`
   - **Команда запуска:** `npm start` или `node server.js`
   - **Порт:** переменная `PORT` (Bothost обычно задаёт её автоматически)
4. Переменные окружения в панели Bothost:

| Переменная | Описание |
|------------|----------|
| `PORT` | Порт (часто задаётся хостингом) |
| `SITE_URL` | Полный URL сайта, например `https://atelier.example.ru` |
| `ADMIN_PASSWORD` | Пароль админа при первом запуске |
| `SESSION_SECRET` | Секрет сессий |
| `NODE_ENV` | `production` |

5. Включите **постоянное хранилище** для папок `data/` и `public/uploads/`, иначе после перезапуска пропадут заказы и фото.

6. Привяжите домен в панели Bothost (SSL выдаётся автоматически).
7. Открывайте сайт по **домену из панели Bothost**, а не по `http://0.0.0.0:3000` — `0.0.0.0` это служебный адрес сервера, браузер по нему не подключается.
8. Проверка: `https://ваш-домен/health` должен вернуть `{"ok":true,...}`.

## Индексация в Google

1. В админке → **SEO и связь** укажите реальный **URL сайта** (`SITE_URL`).
2. Зарегистрируйте сайт в [Google Search Console](https://search.google.com/search-console).
3. Скопируйте код из meta-тега верификации в поле **Google Search Console — код верификации**.
4. В Search Console добавьте sitemap: `https://ваш-домен.ru/sitemap.xml`
5. Опционально: Google Analytics (ID `G-...`) в том же разделе админки.

Также добавьте сайт в [Яндекс.Вебмастер](https://webmaster.yandex.ru) для поиска в Яндексе.

## Структура

```
atelier-site/
├── server.js          # API и сервер
├── public/            # Сайт и админка
├── data/              # JSON-база (настройки, услуги, очередь)
└── public/uploads/    # Загруженные фото
```

## API (кратко)

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/settings` | Настройки сайта |
| GET | `/api/services` | Услуги |
| GET | `/api/queue` | Статус очереди |
| POST | `/api/queue/register` | Взять номер |
| POST | `/api/admin/login` | Вход в админку |

Полный список — в `server.js`.
