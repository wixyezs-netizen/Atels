# Настройка для https://atelmore.bothost.tech

Сейчас домен отвечает **404** на `/` и `/health` — значит запросы до сайта доходят, но **Node-приложение не отдаёт страницы** (не запущено, другой порт или не тот проект в деплое).

## В панели Bothost (точно так)

| Параметр | Значение |
|----------|----------|
| Домен | `atelmore.bothost.tech` |
| **Использовать домен** | ✅ Включено |
| **Порт** | `3000` |
| Язык | Node.js |
| Главный файл | `index.js` или `server.js` |
| Команда запуска | `npm start` |

## Переменные окружения

```
PORT=3000
SITE_URL=https://atelmore.bothost.tech
NODE_ENV=production
ADMIN_PASSWORD=ваш_надёжный_пароль
SESSION_SECRET=длинная_случайная_строка
```

> Поле **PORT** в панели и переменная **PORT** должны совпадать (3000).

## Что должно быть в Git / архиве деплоя

```
atelier-site/
├── package.json
├── server.js
├── index.js
├── public/
│   ├── index.html
│   ├── admin.html
│   ├── css/
│   └── js/
└── data/          (создастся сама)
```

Без папки `public/` сайт не откроется.

## После деплоя — проверка

1. Логи контейнера — должны быть строки:
   - `[atelier-site] Запуск Node.js...`
   - `Ателье-сайт запущен`
   - `Порт: 3000`

2. В браузере:
   - https://atelmore.bothost.tech/health → `{"ok":true,...}`
   - https://atelmore.bothost.tech/ → главная
   - https://atelmore.bothost.tech/admin → админка

## Если снова 404

- Контейнер **падает** при старте → смотрите логи (часто нет `npm install` или нет `node_modules`).
- В деплое **не тот репозиторий** (старый бот без Express).
- Порт в панели **не 3000**.
- Галочка **«Использовать домен»** выключена — включить и **передеплой**.

## Не открывайте

- `http://0.0.0.0:3000` — только для сервера внутри контейнера.
